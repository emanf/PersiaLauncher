**🌍 Sprachen:** [English](README.md) · [فارسی](README.fa.md) · [Русский](README.ru.md) · [Deutsch](README.de.md) · [Español](README.es.md)

> **Deine Minecraft-Welt. Deine Regeln. Dein Launcher.**

PersiaLauncher ist ein übersichtlicher und moderner Launcher zur Verwaltung von Minecraft-Clients, Servern, Konten, Java und Mods.

Erstelle Vanilla-Profile oder umfangreiche Modded-Installationen und behalte alles an einem Ort.

Unterstützt werden:

**Vanilla · Fabric · Forge · NeoForge · Quilt**

## Funktionen

- Verwaltung mehrerer Minecraft-Clients
- Verwaltung von Servern und Welten
- Separate Profile für Versionen und Modpacks
- Installation und Verwaltung von Mods
- Einstellungen für Java, Arbeitsspeicher und JVM-Argumente
- Konten- und Skin-Verwaltung
- Designs, Farben und Fenstereinstellungen
- Frei wählbarer Minecraft-Ordner

## Erste Schritte

1. Lade die neueste PersiaLauncher-Version herunter.
2. Wähle deinen Minecraft-Ordner.
3. Füge ein Konto hinzu oder erstelle ein Profil.
4. Wähle Minecraft-Version und Loader.
5. Erstelle das Profil und starte das Spiel.
