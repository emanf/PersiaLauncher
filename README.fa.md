# ✨ PersiaLauncher

> **دنیای ماینکرفت شما، قوانین شما، لانچر شما**

PersiaLauncher یک لانچر زیبا و کاربردی برای مدیریت کلاینت‌ها، سرورها، اکانت‌ها، جاوا و مادهای ماینکرفت است.

از پروفایل‌های وانیلا تا مجموعه‌های بزرگ مودشده، همه‌چیز را مرتب و آماده اجرا نگه دارید.

پشتیبانی از:

**Vanilla · Fabric · Forge · NeoForge · Quilt**

## امکانات

- ساخت و مدیریت کلاینت‌های مختلف ماینکرفت
- مدیریت سرورها و دنیاهای سرور
- پشتیبانی از چند نسخه و چند پروفایل
- نصب و مدیریت مادها
- تنظیم حافظه، جاوا و گزینه‌های JVM
- مدیریت اکانت‌ها و اسکین‌ها
- پوسته‌ها، رنگ‌ها و تنظیمات نمایش
- انتخاب مسیر دلخواه برای فایل‌های ماینکرفت

5. پروفایل را بسازید و بازی را اجرا کنید.
