پرشیا لانچر یه لانچر مدرن و دوست‌داشتنیه که برای بازیکن‌هایی ساخته شده که می‌خوان دنیاها، پروفایل‌ها، سرورها، مادها و تنظیماتشون رو توی یه جای مرتب مدیریت کنن.

## 🌌 لانچری برای بازیکن‌های واقعی

PersiaLauncher بخش‌های پیچیده رو تا جای ممکن از جلوی دستت برمی‌داره، ولی هر وقت بخوای کنترل کامل رو بهت می‌ده. برای هر نسخه کلاینت جدا بساز، لودر انتخاب کن، جاوا رو مدیریت کن، ماد نصب کن و فایل‌های ماینکرفت رو هر جایی که می‌خوای نگه دار.

### با PersiaLauncher چه کارهایی می‌تونی بکنی؟

- 🧱 ساخت و مدیریت کلاینت‌های Vanilla، Fabric، Forge، NeoForge و Quilt
- 🖥️ مدیریت سرورها و دنیاهای ماینکرفت
- 📦 پروفایل‌های جدا برای نسخه‌ها، مودپک‌ها و سبک‌های مختلف بازی
- 🧩 پیدا کردن و مدیریت مادها
- ☕ تنظیم جاوا، حافظه و آرگومان‌های JVM
- 👤 مدیریت اکانت‌ها و اسکین‌ها
- 🎨 انتخاب تم، رنگ، زبان و تنظیمات نمایش
- 📁 انتخاب مسیر دلخواه ماینکرفت
- 🚀 اجرای سریع کلاینت‌ها با تنظیمات ذخیره‌شده

## 🧭 شروع کار

1. آخرین نسخه [PersiaLauncher](https://github.com/emanf/PersiaLauncher/releases/latest) رو دانلود کن.
2. لانچر رو باز کن.
3. از قسمت **حساب ها** اسمی را برای خودت انتخاب کن و اضافه کن یا یه پروفایل بساز.
4. روی **ساخت** بزن و یه نسخه ماینکرفت را انتخاب کن و روی ساخت کلاینت کلیک کن.
5. روی **کلاینت ها** کلیک کن و نسخه ماینکرفتی که ساختیو اجرا کن.
